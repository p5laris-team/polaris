## 1. 화면 구성 개요

### 1.1 화면 분류

| 분류 | 설명 | 화면 수 |
|------|------|--------|
| 온보딩 | 최초 진입 ~ 첫 미션 도달까지 | 5개 |
| 핵심 루프 | 미션 제안·완료·거절 핵심 플로우 | 5개 |
| 캐릭터 | 캐릭터 상태·돌봄 | 1개 |
| 경제 | 상점·인벤토리·별조각 | 3개 |
| 바이럴 | 카드 공유·외부 유입 | 2개 |
| 부가 기능 | 업적·출석·알림·마이페이지 | 4개 |
| **합계** | | **21개** |

### 1.2 설계 원칙

```
1. 미션 1개 집중 — 리스트 나열 금지. 현재 미션 1개를 캐릭터 대화형으로 제안
2. 캐릭터 말투 일관성 — 노바/무무/쪼리 각각 다른 말투로 모든 화면에 녹아남
3. 광고 슬롯 — 홈/미션 완료 결과/상점 하단에 배너 광고 영역 고정 배치
4. 거절 → 다음 미션 즉시 — 사유 선택 즉시 다음 미션으로 전환 (하루 최대 15개)
5. 공유 유입 추적 — 공유 링크 클릭 시 referral / UTM 파라미터 추적
```

### SCR-001 랜딩

| 항목 | 내용 |
|------|------|
| **화면 ID** | SCR-001 |

#### 화면 구성

```
[상단]
- Polaris 로고 + 슬로건
  "오늘 한 게 없다고? 무무는 봤는데."

[중단]
- 서비스 소개 카피 (2~3줄)

[하단]
- [Google로 시작하기] CTA 버튼 → SCR-002

| 비로그인 | SCR-001 유지 |

#### 화면 구성

```

| 네트워크 오류 | 토스트: "연결이 불안정해요. 잠시 후 다시 시도해주세요." |

### SCR-003 캐릭터 선택

| 항목 | 내용 |
|------|------|
| **화면 ID** | SCR-003 |
| **화면 이름** | 캐릭터 선택 |
| **진입 경로** | SCR-002 신규 가입 완료 후 |
| **관련 UC** | UC-002 |
| **호출 API** | `GET /characters/types` |

#### 화면 구성

```
[상단]
- 안내 문구: "오늘부터 같이할 친구를 골라봐!"
- 진행 표시: 온보딩 1/4

[중단]
- 캐릭터 카드 3종 (가로 스와이프 or 나란히 배치)
  각 카드 구성:
  ├── 캐릭터 썸네일 이미지 (THUMBNAIL 에셋)
  ├── 캐릭터 이름 (노바 / 무무 / 쪼리)
  ├── 한 줄 소개 (summary)
  ├── 성격 키워드 태그 2~3개
  └── 샘플 대사 (sample_line)

[하단]
- [이 친구로 할게요] 선택 확정 버튼 → SCR-004
- 선택 전: 버튼 비활성화
```

#### 캐릭터 데이터

| 코드 | 이름 | 성격 | 말투 |
|------|------|------|------|
| `nova` | 노바 | 밝고 긍정적, 응원형 | 따뜻하고 활기찬 말투 |
| `mumu` | 무무 | 느긋하고 귀여운 공감형 | 짧고 밈스러운 말투 |
| `jjori` | 쪼리 | 솔직하고 직설적인 현실파 | 툭툭 내뱉는 말투 |

### SCR-005 온보딩 설문

| 항목 | 내용 |
|------|------|
| **화면 ID** | SCR-005 |
| **화면 이름** | 온보딩 설문 |
| **진입 경로** | SCR-004 캐릭터 이름 설정 완료 후 |
| **관련 UC** | UC-004 |
| **호출 API** | `GET /users/me/onboarding`, `POST /users/me/onboarding` |

#### 화면 구성

```
[상단]
- 진행 바 (현재 문항 / 9)
- 캐릭터 이미지 + 말풍선 (캐릭터 말투로 질문 전달)

[중단]
- 질문 텍스트
- 선택지 버튼 (라디오 선택형, 문항별 3~5개)

[하단]
- [다음] 버튼 (선택 완료 시 활성화)
- [이전] 버튼 (2문항 이후)
- 마지막 9문항: [완료] 버튼 → SCR-006 (홈)
```

#### 9문항 구성

| 문항 | 내용 | 대응 필드 |
|------|------|----------|
| Q1 | 주로 어디서 생활하나요? | `living_environment` |
| Q2 | 보통 몇 시에 일어나나요? | `wake_time` |
| Q3 | 보통 몇 시에 자나요? | `sleep_time` |
| Q4 | 미션은 어느 정도 난이도를 원하나요? | `mission_intensity` |
| Q5 | 어떤 게 제일 부담스러워요? | `burden_type` |
| Q6 | 요즘 이루고 싶은 게 있나요? | `preferred_goal` |
| Q7 | 알림을 받고 싶은 시간대는? | `notification_preference` |
| Q8 | 날씨에 따라 미션이 달라지면 좋겠나요? | `weather_preference` |
| Q9 | 친구가 어떻게 말을 걸어줬으면 하나요? | `speech_preference` |

#### 중단 복귀 처리

설문 미완료 상태로 앱 재진입 시 `GET /users/me/onboarding`으로 진행 상태 조회 후 마지막 완료 문항 다음 문항으로 복귀.

### SCR-006 홈

| 항목 | 내용 |
|------|------|
| **화면 ID** | SCR-006 |
| **화면 이름** | 홈 |
| **진입 경로** | 온보딩 완료 후 / 앱 재방문 시 |
| **관련 UC** | UC-006, UC-010, UC-020 |
| **호출 API** | `GET /characters/me`, `GET /missions/current`, `GET /star-pieces/balance`, `POST /ads/impressions` |

#### 화면 구성

```
[상단 영역]
- 별조각 잔액 (우측 상단, ✦ N개)
- 알림 아이콘 → SCR-020

[캐릭터 영역]
- 캐릭터 이미지 (상태·장착 스킨 반영)
  - 상태 우선순위: 애정 BAD > 기운 BAD > 포만감 BAD > NORMAL > GOOD
- 캐릭터 이름
- 오늘의 캐릭터 한마디 (캐릭터 말투 반영)
- 상태 인디케이터 3개 (포만감 / 기운 / 애정)
  - 각각 아이콘 + 바 형태
  - BAD 상태: 빨간색 강조 + 흔들림 애니메이션

[업적 목록]
- 탭: 전체 / 달성 완료 / 진행 중

각 업적 카드:
├── 업적 아이콘
├── 업적 이름
├── 업적 설명 (조건)
├── 진행 바 (현재 / 목표)
├── 보상 별조각 (✦ N)
└── 달성 완료: [보상 받기] 버튼 / 수령 완료: "수령 완료" 배지

[업적 유형]
- MISSION_COUNT: 미션 완료 수 달성
- SHARE: SNS 공유 횟수 달성
- ATTENDANCE: 연속 출석 달성
- ITEM_PURCHASE: 아이템 구매 달성
```

```
앱 진입

        │

                │

                ├── 캐릭터 이미지 탭 → SCR-012
                ├── 미션 카드 [해냈어요] → SCR-009
                ├── 미션 카드 [다른 거] → SCR-008
                ├── 퀵메뉴: 상점 → SCR-013
                ├── 퀵메뉴: 인벤토리 → SCR-014
                ├── 퀵메뉴: 업적 → SCR-018
                ├── 퀵메뉴: 공유 → SCR-016
                └── 하단 네비: 마이 → SCR-021
```

| 컴포넌트 | 설명 | 사용 화면 |

원칙: 미션 카드 본문과 완료 버튼을 가리지 않는다
     광고 노출 시 POST /ads/impressions, 클릭 시 POST /ads/clicks 호출

## 6. 화면 전환 흐름

### 6.1 온보딩 플로우

```
SCR-001 랜딩
  → SCR-002 Google 로그인
    → SCR-003 캐릭터 선택
      → SCR-004 캐릭터 이름 설정
        → SCR-005 온보딩 설문 (9문항)
          → SCR-006 홈 (첫 미션 자동 생성)
```

### 6.2 미션 완료 플로우

```
SCR-006 홈
  → SCR-007 미션 카드 확인
    → [해냈어요] SCR-009 미션 완료 질문
      → SCR-010 미션 완료 결과 (별조각 지급)
        → SCR-006 홈 (상태 갱신)
```

### 6.3 미션 거절 플로우

```
SCR-006 홈 또는 SCR-007 미션 카드
  → [다른 거] SCR-008 거절 사유 선택 (바텀 시트)
    → SCR-006 홈 (다음 미션으로 갱신)
      → (15개 초과 시) 오늘 미션 종료 안내
```

### 6.4 공유 플로우

```
SCR-006 홈 퀵메뉴
  → SCR-016 캐릭터 카드 공유
    → [SNS 공유] 별조각 +10 지급
      → SCR-017 공유 링크 랜딩 (외부 사용자 진입)
        → SCR-001 랜딩 or SCR-002 로그인 (referral 추적)
```

### 6.5 돌봄 플로우

```
SCR-006 홈 캐릭터 이미지 탭
  → SCR-012 캐릭터 상세 / 돌봄
    → [밥 주기] POST /characters/me/care/feed
    → [재우기] POST /characters/me/care/sleep
    → [놀아주기] POST /characters/me/care/play
      → 상태 변화 토스트 → SCR-012 상태 갱신
```
